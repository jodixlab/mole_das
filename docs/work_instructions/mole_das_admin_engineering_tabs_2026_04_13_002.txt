MOLE-DAS ADMIN / ENGINEERING TABS
Audience: system administrator, implementation lead, catalog steward, engineering support
Scope: non-routine tabs, remapping, governance, profile maintenance, inventory, and package management

Step 1.0 - DB Paths

		Use this tab when the runtime must be pointed to the correct folders, databases, and asset libraries.

		The tab includes:

			1. Global Config
			2. Core Folders
			3. Databases
			4. Asset DBs (JSON)

		Actions:

			1. Browse
			2. Open
			3. Validate
			4. Reset Defaults
			5. Apply Paths

Step 2.0 - Empirical Conditions

		Use this tab for controlled edits to the empirical formula registry.

		The tab includes:

			1. registry path display
			2. category selector
			3. JSON editor
			4. Save action

Step 3.0 - Catalog Governance

		Use this tab for catalog review, merges, synonym handling, and auditability.

Step 3.1 - Reviewer Identity

		Enter the reviewer identity before performing governance actions.

Step 3.2 - Pending Queue

		Use the queue to:

			1. filter
			2. search
			3. refresh
			4. review counts
			5. approve canonical items
			6. merge to canonical
			7. reject with reason

Step 3.3 - Synonyms / Merge / Audit

		Use the additional areas to:

			1. manage synonyms
			2. merge manufacturers
			3. merge models
			4. review recent governance events

Step 4.0 - Connectivity / Commissioning

		This tab is conditional on the shipped helper/runtime contents.

		Use it only when the commissioning helper is included.

Step 5.0 - Hardware Profiles

		Use this tab to define and maintain communication profiles and channel maps.

Step 5.1 - Profile-Level Actions

		Available actions:

			1. Set Default
			2. Save Config
			3. New
			4. Duplicate
			5. Delete
			6. Build / Update from cfg.hardware
			7. Validate
			8. Export channels.json
			9. Probe (Commissioning), if present

Step 5.2 - Profile Meta

		Profile meta fields include:

			1. profile_key
			2. protocol
			3. timeout_s
			4. endpoint_role
			5. host
			6. port
			7. description
			8. serial_port
			9. baud
			10. parity
			11. stopbits

Step 5.3 - Channel Editing

		Per-channel fields include:

			1. channel_id
			2. unit_id
			3. register
			4. function code
			5. dtype
			6. qty
			7. units
			8. scale
			9. offset
			10. host override
			11. port
			12. description

		Available actions:

			1. Apply Channel
			2. Add Channel
			3. Delete Channel
			4. Poll Selected Channel
			5. List COM Ports
			6. Probe Matrix

Step 5.4 - Diagnostics Support

		Additional utilities include:

			1. Raw RTU Diagnostics
			2. active profile sensor/channel review

Step 6.0 - Inventory Registry

		Use this tab to create, search, store, and bind source instances to the session.

Step 6.1 - Instance Builder

		Builder fields include:

			3. location_id
			4. category
			5. manufacturer
			6. model
			7. variant
			8. serial number
			9. asset tag
			10. manufacture date
			11. install date
			12. engine cycle
			13. cylinders
			14. duty
			15. notes

Step 6.2 - Registry Search / Binding

		Use search fields to locate an instance, then:

			1. Save Instance
			2. Save + Bind Session
			3. Bind Loaded -> Session
			4. Clear
			5. Refresh Search
